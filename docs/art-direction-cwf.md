# Zodiac Bank Cover Art Direction

- **Illustrated cyberpunk scene:** original comic-book digital paintings with a clear central subject, layered silhouettes, and readable action rather than flat iconography.
- **Atmospheric depth:** near-black environments use haze, particles, perspective grids, and subtle circuit traces to create foreground, subject, and background layers.
- **One signal color per scene:** cyan, violet, blue, magenta, green, teal, amber, or red leads each composition while shared cyan/magenta rim light keeps the set cohesive.
- **Security-native props:** radar rings, vault geometry, graph nodes, document shards, signed tokens, memory vials, identity badges, artifact crates, and SIEM beams communicate the scenario without words.
- **Landscape, text-free delivery:** 16:9 art, high contrast, restrained empty space for UI overlays, and no letters, labels, logos, watermarks, or copied source artwork.
